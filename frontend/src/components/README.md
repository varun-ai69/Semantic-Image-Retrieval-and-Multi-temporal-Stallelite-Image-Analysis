# Frontend Components (`frontend/src/components`)

Reusable UI components for map visualization and analyst tools:

- `MapView.jsx`: Core Leaflet base map component.
- `AOIDrawTool.jsx`: Polygon drawing tool producing GeoJSON footprints.
- `PinPointTool.jsx`: Single marker spatial point selection tool.
- `SearchBar.jsx`: Multimodal search query input (text + image).
- `ResultsGrid.jsx`: Semantic search and change candidate cards grid.
- `LocationDetail.jsx`: Before/after slider view and change event details.
- `ReviewQueue.jsx`: Decision logging panel for confirming or rejecting detected changes.
- `ClusterMapView.jsx`: Interactive map displaying HDBSCAN tile clusters.
