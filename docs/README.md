# Documentation (`docs/`)

This directory contains system documentation, architectural designs, project requirement contexts, and evaluation reports.

- `ProjectContext.md`: Primary single source of truth for project requirements, architecture, database schemas, and phase roadmap.
- `architecture-note.md`: Technical breakdown of multi-layer storage, offline guarantees, and intent routing workflows.
- `evaluation-report.md`: Template and log for tracking model accuracy metrics, benchmark harness results, and system latencies.
